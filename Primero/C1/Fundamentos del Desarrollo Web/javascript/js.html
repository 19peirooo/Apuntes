Sentencias de Seleccion:

Sentencia if else:

if(condicion){Instruccion}else{Instruccion}

Sentencia switch:

switch(expresion){case valor1: Instrucciones caso 1; break; default: Si no se cumple ninguna condicion}

Sentencias de Bucle:

Bucle for:

for (inicializacion,condicion,actualizacion){Intrucciones}

for (indice de un array){Instrucciones}

Bucle while y do while:

while (condicion){Instrucciones}

do{Instrucciones}while(condicion);

Sentencia de control:

Sentencia try:

try{Codigo}catch(error){Gestion de error}

Atributo defer: El script se descarga mientras se analiza el html y se ejecuta despues del analisis sin pararlo

Arbol DOM

Define los Objetos y propiedades de los elementos HTML

Permite inspeccionar y modificar elementos HTML

Acceso:

getElementById("id"): Devuelve el elemento con ese id

getElementsById("name"): Devuelve los elemento con ese nombre

getElementsByTagName("tag"): Devuelve los elementos con ese tag

getElementsByClassName("class"): Devuelve los elementos con esa clase

Modificar:

document.write: Para escribir en el documento

element.getAttribute(atributo): Devuelve el valor del atributo

element.setAttribute(atributo,valor): permite modificar el valor del atributo

Propiedad:

element.innerHTML: cambiar el contenido del elemento

element.style.property: Cambiar el estilo del documento

element.attribute: cambiar un atributo de un elemento

Manejadores de eventos

onclick: Cuando pulsas algo, se ejecuta una funcion

onload: Cuando se carga la pagina

setInterval: Funcion se ejecuta cada x tiempo

clearInterval: detiene la ejecucion del setInterval

setTimeoout: Lo mismo que el setInterval pero solo una vez

Metodos

Para Strings:

substring(inicio,fin): Devuelve el trozo de un string

concat(""): Concatena cadenas

parseInt(string): Convierte cadenas a numeros enteros

parseFloat(string): Convierte cadenas a numeros flotantes

.length: Devuelve el numero de cadenas de caracteres

Para Arrays:

join(separador): Une elementos de un array

concat(): Concatena elementos de varios array

pop(): Elimina el ultimo elemento del array

push(): Agrega un elemento del array

shift(): Elimina el primer elemento del array

unshift(): Agrega un elemento al principio del array

reverse(): Coloca los elementos en orden inverso

.length: Devuelve el numeros de elementos

Para Number:

isNaN(): Protege el codigo de valores no numericos

toFixed(digitos): Fija el numero de decimales

toString(base): Convierte un numero a una cadena
