Estructura del documento

Directiva:

Los documentos HTML5 de declaran con !DOCTYPE html

Define la gramatica del documento

Cabecera:

Etiqueta head

Contiene informacion sobre la identificacion y control de la pagina

Etiqueta title: Texto que se muestra en la barra de titulos

Etiqueta meta: Metadatos del documento. Atributo charset = utf-8 para visualizar mas caracteres de otros idiomas

Etiqueta link: Para implementar recursos externos como css o icono en barra de titulos

Etiqueta script: Para incluir javascript al documento

Cuerpo:

Etiqueta body

Donde se representa el contenido de la pagina

Hay elementos de linea y de bloque

Elementos y etiquetas

De texto:

Encabezados: Etiquetas de h1 a h6

Parrafos: Etiqueta p

Fuentes: Etiquetas b o strong para negrita, i o em para cursiva, u para subrayado

Salto de linea: Etiqueta br

Listas:

  • Listas no ordenadas
  • Etiqueta ul
  • Etiqueta li para contenido de la lista
  • Se muestran datos con puntos
  1. Listas ordenadas
  2. Etiqueta ol
  3. Etiqueta li para contenido de la lista
  4. Se muestran datos con numeros
Listas de definicion
Etiqueta dl
Etiqueta dt: Elemento a definir
Etiqueta dd: Definicion. Sale con indent

Comentarios:

Utilizados para explicar porciones de codigo

Empiezan con !-- y acaban con --

Caracteres Especiales:

Comienzan con & y acaban con ;

Ejemplo: #169 es ©

Etiqueta a, de linea

Atributo href: Contiene el la ruta de la pagina web o el archivo

Ruta absoluta: Ejemplo google Ruta relativa: ../ para salir de archivo. Ir a pagina de inicio Para ir a partes del mismo documento. #id del elemento

Integracion Multimedia

Documentos:

Etiqueta object

Atributo type: Tipo de documento

Atributo data: Ruta al documento

Media:

Etiqueta iframe

Atributo src: Enlace

Sirve tambien para poner videos de youtube

Imagenes:

Etiqueta img

Atributo src: Enlace

Atributo alt: Lo que aparece si no se encuentra la imagen

Audio:

Etiqueta audio

Atributo src: Enlace

Atributo controls: Intefaz visual

Atributo autoplay: Se pone al cargar la pagina

Atributo loop: Reproducion en bucle

Video:

Etiqueta video

Atributo src: Enlace

Atributo controls: Intefaz visual

Atributo autoplay: Se pone al cargar la pagina

Atributo loop: Reproducion en bucle

Atributo muted: Silenciar el video
