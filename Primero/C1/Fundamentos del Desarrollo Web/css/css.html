Conceptos Basicos

Para Introducir archivo CSS en HTML: <link href="archivo.css" rel="stylesheet" type="text/css" >

Formato: selector{propiedad1: valor1; propiedad2: valor2; etc.}

* para añadir propiedad a todos los elementos html

Identificadores

ID:

Formato: #nombre{propiedad1: valor1; propiedad2: valor2; etc.}

Es unico, no puede repetirse

Class:

Formato: .nombre{propiedad1: valor1; propiedad2: valor2; etc.}

Se aplica el mismo estilo a los elementos de la misma clase

Modelo de Cajas

content-padding-border-margin

Medidas:

Orden: Sentido horario - Arriba, Derecha, Abajo, Izquierda

margin: 10px; - Se aplica a todos los lados

margin: 10px 50px; - Primero arriba y abajo, Segundo izquierda y derecha

margin: 10px 50px 10px; - Primero arriba, Segundo Izquierda y Derecha, Tercero Abajo

margin: 10px 50px 10px 50px; - Sigue el orden

Pseudoclases

:link - Enlace que no ha sido visitado

:visited - Enlace que ha sido visitado por el usuario

:active - Estilo de un enlace que esta siendo seleccionado por el usuario

:hover - Estilo de un enlace que tiene el cursor encima

:focus - Estilo de un enlace que tiene el foco del navegador

Ejemplo: a:hover{}

Fuentes

@font-face para crear fuentes propias o de internet

Formatos de Fuente: .TTF(True Type Font), .OTF(Open Type Font), .WOFF(Web Open Type Font)

Ejemplo: @font-face{font-family: "nombre", src: url(archivo);}

Visibilidad

Display:

Sirve para esconder elementos

No reserva espacio para el elemento si no se expone en la web

Valor: none

Visibility:

Reserva espacio para el elemento si no se expone en la web

Valores: hidden, inherit, visible y collapse

Define lo visible que es el elemento

0 es no visible y 1 es perfectamente visible

Transformaciones

Propiedad: tranform. Valores: translate,scale,rotate,skew.

Rotar 45º: transform:rotate(45deg)

Escalar por 2: transform:scale(2)

Transladar 60px: transform:translate(60px)

Sesgar 25º: transform:skew(25deg)

Transiciones

Transicion entre 2 estados

Propiedades: transition-property, transition-duration, transition-delay, transition-timing-function.

transition-property: Explica la propiedad a la que se le aplica

transition-duration: Indica la duracion de la transicion

transition-delay: Tiempo en el que se cambia la propiedad y el inicio de la transicion

transition-timing-function: Indica el ritmo de la transicion utilizando la curva de Bezier. Valores: ease, linear, ease-in, ease-out, ease-in-out

Valores Timing Function
Valor Inicio Transcurso Final Equivalente en Bezier
ease Lento Rapido Lento (0.25, 0.1, 0.25, 1)
linear Normal Normal Normal (0, 0, 1, 1)
ease-in Lento Normal Normal (0.42, 0, 1, 1)
ease-out Normal Normal Lento (0, 0, 0.58, 1)
ease-in-out Lento Normal Lento (0.42, 0, 0.58, 1)

#camavinga{transition-property:background-color,transform;transition-duration:3s,2s;} #camavinga:hover{background-color: cyan;transform: scale(0.5);}

Animaciones

Regla: @keyframes. Propiedad: animation.

Sintaxis: @keyframes nombre{from{propiedad1:valor1} to{propiedad2:valor2}}

Se pueden añadir puntos intermedios utilizando los porcentajes

Propiedades
Propiedad Descripcion Valores
animation-name Nombre de la Animacion Identificador puesto en @keyframes
animation-duration Duracion de la animacion Tiempo
animation-timing-function Funcion de Tiempo ease,linear,cubic-bezier
animation-delay Retardo Tiempo
animation-iteration-count Nº de veces Nº infinite
animation-direction Direccion normal, reverse, altenate
animation-play-state Estado running, paused
